## Projects

- **[memory-allocator][alloc]** (C++17). Header-only fixed-size pool and per-frame arena exposed as
  `std::pmr::memory_resource`, with a thread-safe wrapper and a benchmark against `new` and the
  standard-library allocators. Published, version 0.2.1.
- **[VirtualizedTree][tree]** (TypeScript, React). Headless virtualized tree: one hook owns the
  flattening, the visible window, selection, keyboard navigation and ARIA semantics, with five
  ready-made skins over it. Published, with tests, a demo and CI.
- **[Breadcrumb][crumb]** (TypeScript, React). Headless responsive breadcrumb that measures the
  rendered trail against its own box and shortens it only as much as the space demands, with the
  same five skins. Published, with tests, a demo and CI.
- **TooLoL** (JavaScript front end and backend, HTML, CSS). Prototype running locally, REST backend
  in progress. Not published yet.
- **LifeLyst** (Kotlin, Prisma). Kotlin mobile client on a Prisma-backed API. Not published yet.
