## Projects

- **[memory-allocator][alloc]** (C++17). A fixed-size pool and a per-frame arena for games and other
  soft real-time code, header only, both behind `std::pmr::memory_resource`. Sanitizer builds, a
  randomised property test and a benchmark against `new`.
- **[VirtualizedTree][tree]** (React, TypeScript). A tree that renders only the rows you can see.
  One hook holds the logic and five skins put a style on it: MUI, Tailwind, CSS Modules,
  styled-components and plain React. Tests, a demo and CI.
- **[Breadcrumb][crumb]** (React, TypeScript). A breadcrumb that measures itself and gives up as
  little as the space demands: full labels, then initials, then the tail behind an ellipsis. Five
  skins again, and a screenshot script that fails if a row would be clipped.
- **TooLoL** (JavaScript, HTML, CSS). Front end and REST backend, both JavaScript. It is not
  published.
- **LifeLyst** (Kotlin, Prisma). A Kotlin client on a Prisma API. Not published either.
